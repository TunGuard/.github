## TunGuard

TunGuard provides lightweight, secure, and kernel-independent networking tools built entirely in userspace.

It gives you a self-hosted WireGuard VPN server with a web dashboard, API, peer management, configuration generation, QR codes, backup and restore, and an optional SSH gateway.

## Projects

### [`tanguard-binary`](https://github.com/TunGuard/tanguard-binary)

The core TunGuard server and userspace WireGuard engine.

### Core Features

- **Kernel-independent** — Runs without requiring WireGuard kernel modules or host-level WireGuard configuration.
- **Web dashboard** — Manage peers, monitor server status, view traffic statistics, and generate client configurations.
- **QR code generation** — Quickly connect phones and other supported WireGuard clients.
- **REST API** — Automate peer provisioning and server management.
- **Backup & Restore** — Preserve server identity, peers, credentials, and configuration across migrations.
- **SSH Gateway** — Optionally access connected peers through the TunGuard server.
- **Self-hosted** — Your infrastructure, your keys, your VPN.

## Why TunGuard?

WireGuard is intentionally simple. TunGuard focuses on everything around the VPN that makes running it at scale easier:

- Managing peers
- Generating client configurations
- Monitoring connections
- Automating provisioning
- Backing up infrastructure
- Moving VPN servers without rebuilding everything
