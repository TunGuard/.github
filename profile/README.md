# TunGuard

TunGuard provides lightweight, secure, and kernel-independent networking tools built entirely in userspace.

## Projects

* [tanguard-binary](https://www.google.com/search?q=https://github.com/TunGuard/tanguard-binary): The core userspace WireGuard engine, featuring a web dashboard, QR code config generation, backup management, and an optional SSH gateway.

## Core Features

* **Kernel-independent:** Runs tunnels on standard Linux environments without kernel modules or host configuration.
* **Web dashboard:** Manage peers, track live statistics, and download configuration profiles or scan QR codes.
* **REST API:** Automate peer provisioning and server monitoring.
